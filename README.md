# LANVEX SMP — Public

> Public assets, media, resources, and documentation for the LANVEX SMP project.

This repository is the public archive for **LANVEX SMP** and related LANVEX projects.

It contains promotional artwork, branding, screenshots, videos, player creations, server resources, plugins, resource packs, and other files that are useful to the LANVEX community and its services.

🌐 **Public Library:** [public.lancsmp.ru](https://public.lancsmp.ru/)

---

## 📂 Repository Contents

| Directory / File             | Description                                                              |
| ---------------------------- | ------------------------------------------------------------------------ |
| `Player Creations/`          | Creations and media made by members of the community                     |
| `Plugins/`                   | Public server plugins and related resources                              |
| `Video_Captures/`            | Captured gameplay and server footage                                     |
| `Videos/`                    | LANVEX-related video files                                               |
| `resource packs/`            | Resource packs and related Minecraft resources                           |
| `*.png` / `*.jpg` / `*.webp` | Promotional artwork, screenshots, branding, UI graphics, and other media |
| `Logos.zip`                  | Collection of LANVEX/server logos                                        |

The repository also contains assets from different stages of the project's development, including older LANCSMP/Lancasters branding and newer LANVEX branding.

## 🏷️ LANVEX

**LANVEX SMP** is a community-driven Minecraft SMP project focused on survival gameplay, custom content, player creativity, and community interaction.

The project has evolved through several names and iterations. As a result, this repository preserves both current LANVEX material and older assets from previous versions of the project.

Legacy files are kept for archival and historical purposes and may not represent the current LANVEX branding.

---

## 🎨 Branding

Current LANVEX branding assets include:

* LANVEX SMP logos
* LANVEX Studios logos
* Server icons
* Promotional backgrounds
* Website graphics
* Social and announcement graphics

When creating new LANVEX material, prefer the current LANVEX branding over archived/legacy assets.

## 🕒 Archive & History

This repository is also intended to preserve the project's history.

Older logos, screenshots, promotional material, and other assets may remain available even after they are no longer actively used.

Files should generally **not be deleted solely because they are outdated**. If an asset is obsolete, prefer keeping it as part of the archive unless there is a specific reason to remove it.
